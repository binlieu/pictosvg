# Testing

## 1. Running the tests

```bash
php artisan test                       # all 71 tests (Unit + Feature)
php artisan test --testsuite=Unit      # 19 unit tests
php artisan test --testsuite=Feature   # 35 feature tests
php artisan test --filter=test_logo_converts
```

The test suite needs Potrace and ImageMagick installed, because the conversion tests run the real
tools. The tests do not mock the tracer.

`phpunit.xml` sets `CACHE_STORE=array`, `SESSION_DRIVER=array`, `QUEUE_CONNECTION=sync`,
`DB_CONNECTION=null` and `BCRYPT_ROUNDS=4`. `tests/TestCase.php` gives each test its own storage
directory under the system temporary directory. It removes that directory afterwards and disables
the throttle middleware.

The result reported for this milestone: **71 tests passing**, reported by the developer on
2026-11-21 (macOS, PHP 8.3.23, Laravel 13.43.0). Re-run the suite to confirm on your machine.

`scripts/test-summary.sh` runs `php artisan test` and parses the final line of output as JSON. The
JSON output format has **not been verified** in this milestone.

## 3. What the tests check (conversion tests)

- The output parses as XML and as an SVG with the required root attributes.
- The output contains `<path>` elements and cubic curves, and no `<image>`, `base64` or `transform`.
- Physical width and height follow the requested unit, and the aspect ratio matches the source.
- Point sampling of the fill, using the non-zero winding rule, confirms that holes are holes and
  that sharp corners stay sharp (3 px inside and outside each corner).
- Optimisation keeps the fill equivalent to the raw trace on a 20 × 20 sample grid, with at most two
  sample points changed.
- Outline Cut output has only closed contours, with no duplicates, and a warning.

## 4. Fixtures

Fixtures live in `tests/fixtures/` and are generated by `scripts/make-fixtures.sh`. All are
synthetic artwork made by ImageMagick, except `rotated.jpg`, which is a generated JPEG with an
EXIF orientation tag inserted by a small Python script.

| Fixture | Size | Used for |
|---|---|---|
| `logo.png` | 600 × 400 | Black ring, square and triangle on white. Core logo test; holes; corners; download. |
| `logo.webp` | 600 × 400 | WebP upload. |
| `transparent-logo.png` | 500 × 500 | Transparent PNG with a ring and a bar. |
| `light-on-transparent.png` | 400 × 400 | White star on transparency. Alpha-shape branch. |
| `text.png` | 900 × 420 | Text-heavy image. Glyph counts and counters. |
| `line-drawing.png` | 800 × 600 | Thin strokes, rings and hatching. Line Art. |
| `illustration.png` | 800 × 800 | Several overlapping coloured shapes. Optimisation. |
| `noisy-logo.png` | 600 × 400 | Logo plus 1–2 px specks and one 3 × 3 dot. Noise Removal. |
| `vehicle-photo.jpg` | 1000 × 640 | **Synthetic** photo-like scene with gradients and noise. Not a real photograph. |
| `rotated.jpg` | 400 × 200 stored, 200 × 400 displayed | EXIF orientation 6. |

Regenerating the fixtures:

```bash
PICTOSVG_MAGICK_BIN=magick ./scripts/make-fixtures.sh
```

Notes:
- The script uses the macOS font `/System/Library/Fonts/Supplemental/Arial Bold.ttf` by default.
  Set `PICTOSVG_FIXTURE_FONT` on other systems.
- The script needs `python3` for `rotated.jpg`.
- The vehicle fixture uses `+noise Gaussian` without a seed. Regenerating it changes the pixels, so
  counts asserted against it may change.
- Regenerating any fixture can change the asserted counts. Check the tests after doing so.

## 5. Verification levels for testing

- **Automated Tested:** the tests above. They run real conversions and check the output.
- **Visual Reviewed:** fixture outputs were rendered and looked at by the developer agent. This is
  not a human review.
- **Importer Verified:** Not Verified. No LightBurn, VCarve/Aspire or Inkscape check exists.
- **Machine Verified:** Not Verified.

## 6. Not tested

- Browser behaviour: drag and drop, paste, zoom, pan, view switching and debounced reconversion.
  There are no browser tests.
- Rate limiting. The test suite disables the throttle middleware.
- The 1-in-20 cleanup sweep on upload, which is random.
- The timeout path (`trace_timeout`).
- Uploads close to 20 MB. Only the byte-limit check with `max_upload_mb = 0` is tested.
- Ubuntu, Nginx and PHP-FPM deployment.
- ImageMagick 6 and other ImageMagick builds.
- Real photographs.
- Concurrency: two conversions on one id at the same time.
- Coding style (`./vendor/bin/pint --test`). Pint has not been run for this milestone.
- `scripts/check.sh` as a whole. It exists, but it has not been run for this milestone. Its documentation
  step expects a `README.md`, which does not exist, so the gate fails there until one is added or the check changes.
