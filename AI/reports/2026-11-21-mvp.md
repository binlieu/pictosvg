# MVP Milestone Report

Date: 2026-11-21. Project: PicToSVG.

## Scope delivered

A complete vertical slice from upload to a downloaded, physically sized SVG. The product works without login,
database or AI credentials.

- UPLOAD-001: JPG, PNG and WebP intake, validated by content, with size and pixel limits.
- PRE-001: ImageMagick preparation with orientation, transparency handling, contrast, blur, invert and threshold.
- TRACE-001: Potrace 1.16 tracing with Engrave, Outline Cut and Line Art presets.
- OPT-001: Speck removal, flat-curve straightening, straight-run merging and duplicate removal. No overlap cleanup.
- VIEW-001: One Blade page with three steps, sliders, Advanced Settings, zoom and pan, two views and two backgrounds.
- EXPORT-001: mm and inch sizing with a correct viewBox, validated output and re-sizing that changes only the root dimensions.
- AI-001: At the MVP milestone, gating only. Later the same day AI Redraw was implemented with OpenAI image editing (see `docs/17-change-log.md`); not verified against the live API.
- SYS-001: Private storage, HMAC-token access, 60-minute expiry, cleanup, rate limits and process limits.

## Key decisions

- Potrace is the only tracing engine. VTracer is not integrated ([ADR 0001](../../docs/adr/0001-potrace-as-tracing-engine.md)).
- Stateless id and HMAC token access. No database ([ADR 0002](../../docs/adr/0002-stateless-token-access-no-database.md)).
- ImageMagick is called as a CLI, not through the PHP extension ([ADR 0003](../../docs/adr/0003-imagemagick-cli-instead-of-imagick-extension.md)).
- AI Redraw was gated and not implemented at this milestone; see ADR 0005 for the later implementation.

## Discrepancies found between code and facts or documents

1. **Orientation metadata (resolved).** The reported size used to be swapped only for JPEG through PHP's `exif`
   extension, so a rotated PNG or WebP could be stretched. Orientation is now read with ImageMagick for every
   format. Covered by `UploadTest::test_png_orientation_metadata_is_honoured_like_jpeg`. KI-01.
2. **Fixture comment disagrees with the speck formula.** The comment says a 3 × 3 dot needs Noise Removal 7 or more.
   The formula gives about 9 (derived). KI-03.
3. **`docs/API.md`** shows a shorter `/api/ai/status` message than the code, and names the download parameter `{id}`
   where the route uses `temporaryId`. KI-12.
4. **Test comments cite IDs with no spec** (`EXPORT-002`, `EXPORT-003`, `SYS-002`, `UPLOAD-002`). KI-13.
5. **Test bound for result versions** is 6 where the setting is 5. KI-14.
6. **`scripts/check.sh` exists but was not run.** Its documentation step expects `README.md`, which is absent, so the
   gate fails there. Pint has not been run. KI-17.
7. **`scripts/test-summary.sh`** expects JSON output from `php artisan test`. The format is unverified. KI-17.
8. **Fixture generator** uses a macOS font path, needs `python3`, and has an unseeded noise step for the vehicle photo. KI-10.
9. **Empty directories:** `database/migrations/`, `app/Console/Commands/` and `AI/specs/` contain no files. The
   migrations directory exists, so "migrations removed" is accurate only in that it is empty.
10. **AI button** is always shown (disabled). The master spec allows showing it only when configured. KI-12.
11. **Outline stroke divisor** changed during the milestone. KI-16.
12. **`APP_DEBUG=true`** in `.env.example`. KI-18.
13. **`AGENTS.md`** is referenced by project guidance but absent.

No place where the code contradicted the supplied facts was found, other than items 1 and 2, which are gaps the facts did not cover.

## Known limitations

- No colour or centerline tracing. Line Art and Outline Cut trace outlines, and Outline Cut traces both edges of a line.
- No intersection detection.
- Photographs are approximate. The vehicle fixture is synthetic.
- Rate limits are per IP and are not tested. The download token is in the query string. Expiry is not refreshed by activity.
- No lock on a conversion id.
- Ubuntu, ImageMagick 6 and Potrace on Linux are not verified.
